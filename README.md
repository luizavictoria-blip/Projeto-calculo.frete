Calculadora de Frete
Descrição
Este projeto consiste em uma aplicação Java desenvolvida para calcular o valor do frete de acordo com o valor de uma compra. O sistema utiliza regras de negócio definidas e possui testes automatizados para verificar seu funcionamento.
Objetivo
Aplicar conceitos de testes de software, incluindo testes unitários, parametrizados, integração, classes de equivalência, valores-limite e regressão.
Regras de negócio
Compras abaixo de R$ 100,00: frete de R$ 20,00.
Compras de R$ 100,00 até R$ 299,99: frete de R$ 10,00.
Compras a partir de R$ 300,00: frete grátis.
Valores negativos não são aceitos.
O valor total é a soma da compra com o frete.

Como executar
Clonar o repositório.
Abrir o projeto no IntelliJ IDEA.
Aguardar a importação das dependências Maven.
Executar a classe Main.
Informar o valor da compra no console.
Como executar os testes
Os testes podem ser executados pelo IntelliJ IDEA ou pelo Maven.
Pelo IntelliJ:
Abrir a pasta de testes.
Executar todos os testes.
Pelo terminal:
mvn test
Técnicas de teste
Testes unitários.
Testes parametrizados.
Classes de equivalência.
Análise de valores-limite.
Testes de integração.
Testes de regressão.
Testes manuais.
Resultados
Os testes automatizados foram executados após as correções realizadas no projeto, apresentando resultados aprovados.
