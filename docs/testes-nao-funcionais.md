Testes Não Funcionais — Calculadora de Frete
1. Objetivo
Os testes não funcionais têm como objetivo avaliar características de qualidade do sistema, além de verificar se os cálculos estão corretos.
Neste projeto, foram considerados aspectos de usabilidade, confiabilidade, desempenho e segurança.
2. Usabilidade
A usabilidade está relacionada à facilidade de utilização do sistema.
Verificações:
O programa apresenta instruções para o usuário?
É fácil informar o valor da compra?
Os resultados do frete e do total são apresentados de forma clara?
Quando o usuário informa um valor inválido, a mensagem de erro é compreensível?
Critério de aceitação: o usuário deve conseguir utilizar o programa e compreender os resultados sem dificuldade.
3. Confiabilidade
A confiabilidade está relacionada à capacidade do sistema de apresentar resultados corretos e consistentes.
Verificações:
O sistema calcula corretamente o frete em todas as faixas?
Os valores-limite são tratados corretamente?
O sistema rejeita valores inválidos?
Os testes automatizados continuam passando após alterações?
Critério de aceitação: os resultados devem respeitar as regras de negócio e não apresentar inconsistências.
4. Desempenho
O desempenho está relacionado ao tempo necessário para executar os cálculos.
Verificações:
O cálculo é realizado rapidamente?
O sistema apresenta o resultado sem demora perceptível?
A execução dos testes automatizados ocorre em tempo adequado?
Critério de aceitação: o cálculo deve ser realizado de forma rápida, sem demora perceptível para o usuário.
5. Segurança e validação
A segurança considera o tratamento das entradas informadas pelo usuário.
Verificações:
Valores negativos são rejeitados?
Entradas não numéricas são tratadas?
O sistema evita realizar cálculos com entradas inválidas?
O programa apresenta mensagens de erro sem encerrar inesperadamente?
Critério de aceitação: entradas inválidas devem ser rejeitadas ou tratadas adequadamente, evitando resultados incorretos.
6. Resultado
Os aspectos de qualidade foram analisados considerando o comportamento do sistema durante os testes automatizados e manuais.
O projeto busca garantir facilidade de utilização, resultados consistentes, execução rápida e tratamento adequado de entradas inválidas.
7. Conclusão
A análise dos aspectos não funcionais contribuiu para verificar não apenas se a calculadora realiza os cálculos corretamente, mas também se apresenta um comportamento adequado para o usuário.
